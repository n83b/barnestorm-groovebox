# Broken Machinery development pack

These eight samples are original, procedurally generated development assets
created by `tools/generate-development-pack.mjs`.

They are dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). They are intended
to make the browser prototype immediately playable and can be replaced by the
final curated pack without changing the manifest or audio-engine APIs.
